# Memory Card Game

Full stack Memory Match game with JWT login, MongoDB score saving, leaderboard, history, and modern dark UI.

## Getting Started

1. Copy `.env.example` to `.env` and set `MONGODB_URI` and `JWT_SECRET`.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the app:
   ```bash
   npm run dev
   ```
4. Open `http://localhost:4173`.

## Features

- 4×4 card grid with 8 pairs
- Random shuffle each game
- Flip animations and match detection
